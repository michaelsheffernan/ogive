# Security

Ogive runs on your machine. It reads and writes rocket files and drives OpenRocket in the same process.

If you find a way to make it read or write files it shouldn't, run code it shouldn't, or leak anything, please
tell me privately. Use **Report a vulnerability** on this repo's Security tab. Please don't open a public issue
for it.

It's just me maintaining this, so give me a few days to reply.

In scope: the code in this repo (the MCP server, the CLI, the Claude Desktop bundle).
Bugs in OpenRocket itself belong with [OpenRocket](https://github.com/openrocket/openrocket).
